## 2. 收入结构：两家都在变成“卖 Token 的公司”

**智谱**：收入结构基本整个换了一遍。

| 业务 | H1 2026（亿元） | 占比 | 同比 | 毛利率 |
|---|---|---|---|---|
| 开放平台及 API（云端） | 8.252 | 86.5%（去年同期 15.2%） | +2,735.7% | 24.6%（去年同期 −0.4%） |
| 企业级智能体 | 0.556 | 5.8% | +304.4% | 35.6%（去年同期 64.6%） |
| 企业级通用大模型（私有化） | 0.670 | 7.0% | −54.6% | 42.3%（去年同期 58.5%） |
| 技术服务及其他 | 0.061 | 0.7% | +1,166.7% | 9.4% |

- 本地化部署合计 1.287 亿元（−20.5%），毛利率从 59.1% 降到 37.9%。
- 公告披露：Token 调用量较年初增长 40 倍以上，其中 Coding Plan 增长 23 倍以上；**API 平均售价提高约 101%**。量和价同时上涨，这次增长不是靠降价换来的。
- 电话会披露：2026 年 8 月的 MaaS ARR 为 **16 亿美元**（按 8 月收入 × 12 计算）。这个数不在财报里，属于管理层口径。

**MiniMax**：从偏 C 端转向以 B 端 / API 为主，海外收入占大头。

| 业务 | H1 2026（百万美元） | 占比 | 同比 |
|---|---|---|---|
| 开放平台及其他 AI 企业服务 | 73.9 | 63.4%（去年同期 30.3%） | +703.1% |
| AI 原生产品（海螺 AI 等） | 42.6 | 36.6% | +100.9% |

- 按地区：中国内地 45.7（39.2%），其他地区 70.8（60.8%，去年同期 71.8%）。国内收入增长更快（+434%）。
- H1 收入已经超过 2025 全年的 7,900 万美元。
- 媒体报道的业绩会口径：7 月 Token 消耗是 1 月的 20 倍，Q2 收入环比增长 81.8%，8 月 ARR 预计超过 8 亿美元（[Investing.com](https://es.investing.com/news/stock-market-news/por-que-sube-hoy-la-accion-de-minimax-93CH-3822446)、[ChainCatcher](https://www.chaincatcher.com/ja/article/2286648)）。这些不在公告里。

## 3. 关键判断

**① 增长：两家都增长很快，智谱的体量和加速度更大。**
智谱 H1 收入约 1.42 亿美元，比 MiniMax 的 1.17 亿美元高约 22%，增速也更高（400% vs 283%）。按 8 月 ARR 看，智谱约 16 亿美元，MiniMax 约 8 亿美元以上，差距还在扩大。两家的增长都主要来自 Coding / Agent 场景的 API 调用。

**② 毛利：方向相反，但都不高。**
- 智谱整体毛利率从 50% 降到 26.4%，原因是业务结构变了：高毛利的私有化项目收缩，低毛利的 API 成为主体。不过 API 本身的毛利率从 −0.4% 升到 24.6%。公司提到国产芯片推理集群达到 10 万卡级，单位 Token 推理成本较年初下降 80%。
- MiniMax 毛利率从 12.1% 升到 17.9%，主要靠基础设施效率提升，但仍低于智谱。
- 两家每 1 元收入扣掉直接算力成本后，只剩约 0.2–0.26 元，离覆盖研发还很远。

**③ 亏损：智谱的“单位亏损”收敛更快，MiniMax 的亏损绝对额翻倍。**
- 两家的经调整净亏损几乎一样，都是约 2.93 亿美元。但智谱收入更高，经调整亏损率 206%，MiniMax 是 251%。
- 智谱经调整亏损同比只多了 12%，研发只增长 33.6%。MiniMax 研发增长 138.8%，经调整亏损增长 111%。
- 增量对比：智谱新增毛利约 1.56 亿元，新增研发约 5.37 亿元；MiniMax 新增毛利约 0.17 亿美元，新增研发约 1.73 亿美元。**两家新增的毛利都只能覆盖新增研发的 10%–30%，目前还看不到规模效应。**
- 两家 IFRS 亏损同比下降，主要原因是上市后优先股 / 投资者金融工具的公允价值损失消失了，不是主业有了改善。看经调整口径更能反映真实情况。

**④ 费用纪律：两家都在减少销售投放。**
两家销售费用都在下降（智谱 −14.8%，MiniMax −17.9%），增长主要来自模型能力带来的自然增长，而不是买量。智谱的管理费用也减少了 44%。MiniMax 的管理费用翻倍，但占收入的比例从 48.8% 降到 25.9%。

**⑤ 资金与算力投入：智谱的弹药多得多。**
- 报告期末，智谱账面现金加短投约 6.7 亿美元，按 H1 经调整亏损粗算，约够 2.3 个半年；MiniMax 有 13.2 亿美元，约够 4.5 个半年。
- **期后两家都大规模融资**（见港交所公告）：
  - 智谱：7 月配售净额约 313.7 亿港元，9 月配售净额约 156.6 亿港元，外加 201.4 亿元人民币零息可转债（净额约 30.1 亿美元）。合计约 **706 亿港元（≈90 亿美元）**。
  - MiniMax：7 月配售净额约 94.4 亿港元，外加 65 亿港元零息可转债（净额约 64.3 亿港元）。合计约 **159 亿港元（≈20 亿美元）**。
- 算力相关的资产负债表信号：智谱预付计算服务费从 1.16 亿元涨到 12.44 亿元，应付计算服务费 14.27 亿元，还收购了北京红钻（物业设备约 3.6 亿元）和中科加禾 60% 股权。MiniMax 的物业设备从 160 万美元涨到 7,490 万美元，预付款大幅增加。MiniMax 还把阿里云算力服务协议的年度上限提高到 2026–2028 年合计 12 亿美元。

## 4. 风险与关注点

1. **毛利率天花板**：API 已是两家的主要收入，但毛利率只有 18%–25%。智谱 GLM-5.3-Flash 的定价只有 5.2 的十分之一。低价模型扩大用量后，能否守住毛利率还需要观察。
2. **研发开支刚性**：研发是收入的 2.2–2.5 倍，而且训练算力还在扩张。短期内看不到盈亏平衡。有卖方把智谱的盈亏平衡预测提前到 2028 年（[China AI Dispatch](https://chinaaidispatch.substack.com/i/213857574/zhipu-grew-revenue-400-and-its-gross-margin-halved) 引用招商证券国际）。
3. **ARR 口径**：两家的 ARR 都是管理层用单月收入 × 12 算的，不是审计数字，受单月波动和大客户集中度影响大。智谱前十大客户的日均调用量较年初增长了 98 倍。
4. **应收与现金质量**：智谱应收账款从 3.03 亿元涨到 7.83 亿元，6 个月以上账龄约 1.33 亿元。MiniMax 应收从 1,070 万美元涨到 3,910 万美元。
5. **估值波动**：智谱股价 6 月曾突破万亿港元市值，之后回撤约 60%。两家股价对模型发布和 ARR 数据都非常敏感。

## 5. 一句话结论

**智谱**：规模更大、增长更快、单位亏损收敛更明显，期后融资约 90 亿美元，弹药充足。代价是整体毛利率被 API 拉低，而且收入高度依赖 Coding 场景的 API。
**MiniMax**：全球化和 C 端产品是它的差异化优势，毛利率在改善，但绝对水平低，研发与亏损增速接近收入增速，规模效应还没出现。
两家的共同点是：**收入已经证明有需求，但还没证明卖 Token 能养活前沿模型研发。**
