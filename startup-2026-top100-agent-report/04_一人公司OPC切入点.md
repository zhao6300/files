# 适合一人公司（OPC）的切入点

- **依据：** 前三份报告，以及2026年关于一人公司、单人创业者和平台生态的新闻检索（原始结果见 [data/一人公司OPC_检索结果.txt](./data/一人公司OPC_检索结果.txt)）
- **说明：** 本文只是分析，不构成投资建议。

## 结论

适合一人公司的方向有几个共同点：
- 获客靠产品、内容或平台分发，不靠销售团队；
- 交付能交给 Agent 自动完成；
- 不需要牌照、硬件和大额资本；
- 最好在巨头的生态里做补充，不站在巨头的路线上正面竞争。

| 不适合一人公司 | 原因 |
|---|---|
| 大模型、算力芯片、人形机器人整机、国防、能源 | 需要重资本、硬件或政府渠道 |
| 企业级身份安全、支付、保险、预测市场 | 需要客户信任、合规认证、牌照和销售团队 |
| 通用编程工具、通用助理 | 巨头正在正面竞争 |

## 七个切入点

### 1. 平台生态里的应用和插件（现在窗口最明显）
- **依据：**
  - OpenAI 于2026-09-30推出 ChatGPT 应用商店。
  - Anthropic 的 Claude Marketplace 已有2000多个连接器和插件。
  - Shopify 在结账环节支持了 WebMCP。
  - Amazon 向 Agent 开放了卖家后台。
- **做什么：** 做某个行业专用的 ChatGPT 应用或 Claude Skill，或者给某个 SaaS、数据源写 MCP 连接器。
- **为什么适合：** 平台负责带流量，你只需要把一个具体问题解决好。
- **风险：** 平台可能改规则、调抽成或亲自下场，所以要尽早把用户沉淀到自己手里。

### 2. 帮中小商家和网站做“Agent 化改造”
- **依据：** Profound 靠帮企业做 AI 搜索优化（GEO），估值18亿，说明需求真实存在。它服务的是大企业，中小商家这块还没人认真做。
- **做什么：**
  - 帮独立站、本地商家、中小 SaaS 做 AI 搜索优化
  - 生成 Agent 能读懂的文档
  - 部署 MCP 或 WebMCP 接口，让 Agent 能直接下单
- **收费方式：** 一次性搭建费加月度维护费。交付流程可以标准化，一个人能服务很多客户。

### 3. AI 驱动的服务公司：卖结果，不卖软件
- **依据：**
  - 有报道称，一位单人创业者8个月做出了营收数百万美元的 AI 原生服务公司。
  - 垂直 Agent 公司（Harvey、EliseAI、Rillet、Corgi）证明“按结果收费”行得通。
- **做什么：** 选一个熟悉的超窄细分，用 Agent 在后台交付，对外直接卖“做完的活”。例如：
  - 跨境电商的商品上架和多语言详情页
  - 招投标文件
  - 报关单证
  - 保险理赔材料整理
  - 诊所的预约和回访
- **为什么适合：** 先靠服务赚钱并验证需求，再逐步做成产品。行业知识就是护城河。

### 4. 爆款传播的小工具（尤其适合出海）
- **依据：**
  - Base44 在2025年由一人开发，6个月后被 Wix 以约8000万美元收购。
  - Wispr Flow 做语音输入，估值20亿。
  - Higgsfield 证明 AI 视频模板的需求很大。
- **做什么：** 针对一个高频的小痛点做工具，比如语音工作流、某个平台专用的 AI 视频或图片模板、某类文档的一键处理。
- **风险：** 现在用 AI 写代码门槛很低，别人很容易抄，要靠速度、品牌和内容分发取胜。独立开发者 idoubi 一年做了11个产品，他自己说“也许砍掉一半会更开心”，说明专注比铺量更重要。

### 5. 细分领域的训练数据、评测集和强化学习（RL）训练环境
- **依据：** AfterQuery 5个月估值涨10倍；Mercor 年化收入（ARR）超20亿；Arga Labs 专门为企业搭建训练 Agent 的环境。
- **做什么：** 如果你在医疗、法律、财税、工业软件等领域有专业背景，可以做这个领域的评测集，或者把某个行业软件做成可以训练 Agent 的仿真环境，卖给 Agent 创业公司。
- **为什么适合：** 专业知识难以复制，客户少但付费高。

### 6. 开源的 Agent 安全小工具，以被收购为目标
- **依据：**
  - 出现了 Agent 插件漏洞（Plugin4Shell）、编程 Agent 把内部截图泄露到公开的 GitHub 等事件。
  - Aegis 成立9个月就被 Upwind 收购。
  - AIR 专门审查 Agent 使用的插件，拿到5000万种子轮。
- **做什么：** 做一个非常具体的开源工具，比如 MCP 服务的安全扫描器、Agent 插件审计工具、编程 Agent 的数据防泄漏检查。先免费让开发者用起来，再推出付费的团队版。
- **路径：** 一人公司很难直接卖给大企业，但在开发者中广泛使用的开源工具，容易被安全公司看中并收购。

### 7. 国内：借助政策，做企业 AI 落地的个人顾问
- **依据：**
  - 报道称全国一人公司已超过50万家。
  - 杭州对一人公司的支持最高1000万元，重庆提供最高600万元的创业贷款。
  - 绿地集团在14个城市开了首批15个 OPC 社区。
  - 已有一人公司从 OPC 社区起步，半年扩张到30人。
- **做什么：** 为中小企业驻场落地 Agent（FDE 模式的个人版），比如在企业微信、飞书、钉钉里做业务机器人；或者做 AI 短剧、内容类的“超级个体”。
- **建议：** 先入驻 OPC 社区，拿免费工位、算力补贴和政策资金，把成本压下来。

## 技术栈参考

| 用途 | 工具 |
|---|---|
| 写代码 | Claude Code、Cursor、Lovable |
| 后端和部署 | Supabase、Vercel |
| 收款 | Stripe（海外），或国内的支付服务 |
| 自动化 | 用 Agent 处理客服、内容和运营。有创业指南直接建议“前10个员工都用 AI Agent” |

## 自检的5个问题

1. 不找销售，你能找到第一批10个付费客户吗？
2. 交付工作的80%以上能交给 Agent 完成吗？
3. 需要牌照、硬件或者大额预付成本吗？需要的话就不适合。
4. 客户能在一个月内付钱吗？回款快对一人公司很重要。
5. 如果 OpenAI 或 Anthropic 下个月上线同样的功能，你还剩下什么？比如行业知识、用户关系、自有数据。

## 按背景选择

| 你的背景 | 优先方向 |
|---|---|
| 有行业经验 | 第3条（AI 服务公司）或第5条（专业数据） |
| 开发者 | 第1条（平台插件）或第6条（开源安全工具） |
| 在国内 | 第7条，可以和其他任何一条叠加 |
