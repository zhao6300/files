# 一人公司三个方向的落地方案

- **三个方向：**
  - A. 帮中小商家和网站做“Agent 化改造”
  - B. 个人版 FDE（前沿部署工程师）：在企业微信、飞书、钉钉里驻场落地 Agent
  - C. AI 短剧、AI 内容“超级个体”
- **依据：** 2026年4–9月的新闻检索，原始标题见 [data/OPC三方向_检索结果.txt](./data/OPC三方向_检索结果.txt)
- **说明：**
  - 文中的**报价、产能、收入测算都是参考假设**，不是市场数据，请按当地行情调整。
  - 标“转引”的数据来自二手文章，没有核对原始出处。
  - 本文不构成投资、法律或税务建议。

## 总览

| | A. Agent 化改造 | B. 个人版 FDE | C. AI 短剧、内容 |
|---|---|---|---|
| 本质 | 让商家被 AI 找到、被 Agent 调用 | 把 Agent 装进企业的日常流程 | 用 AI 低成本生产内容 |
| 客户 | 中小商家、独立站、本地服务、中小 SaaS | 10–300人的中小企业 | 平台（分账）、片方、品牌商家、海外用户 |
| 起步门槛 | 低，懂内容加一点技术 | 中，要懂业务流程和集成 | 低，但做到头部很难 |
| 现金流 | 快，按项目加月费 | 快，按项目加月费 | 慢且波动大 |
| 主要风险 | 国内黑灰产多、平台规则变化 | 客户需求不稳定、项目范围失控、数据合规 | 产能过剩、平台政策、版权 |
| 推荐程度 | ★★★★ | ★★★★★ | ★★★（前提是做差异化） |

**最有竞争力的做法是把三个方向组合起来：** 选一个垂直行业，给商家提供完整链路。
- C 负责**获客**：用内容吸引客户
- A 负责**被找到**：让客户在 AI 里能搜到商家
- B 负责**接住并转化**：用 Agent 跟进线索、完成转化

详见第四节。

## A. 帮中小商家和网站做“Agent 化改造”

### A1. 为什么是现在

**海外：**
- 流量入口在从搜索转向 AI：BrightEdge 统计，AI 带给网站的推荐流量里，ChatGPT 占95.1%；另有报道称 ChatGPT 的推荐流量同比增长了101%；Similarweb 数据显示 Claude 的访问量增长了540%。
- 已有行业媒体指出：“AI 可见度已经不只是推荐流量的问题”。也就是说，用户直接在 AI 里拿到答案，不一定再点进网站。
- 网站开始被 Agent 直接操作：
  - Chrome 在推广 WebMCP，让网站把自己的功能暴露给 Agent 调用。
  - Shopify 用 WebMCP 向所有店铺开放了 Agent 访问，浏览器里的 Agent 可以直接读取、填写并提交结账。
  - Mastercard 推出了面向 Agent 交易的信任服务。
- **对手也来了：** Meta 把 Muse Agent 开放给了小企业，可以从广告账户一键接入。这意味着“基础版的 Agent 化”会被平台免费提供，服务商必须做平台做不到的部分。

**国内：**
- GEO（面向 AI 搜索的优化）已经形成一个服务商行业。大量“某城市 GEO 服务商盘点”类的软文说明，**低端市场已经很拥挤**。
- 黑灰产问题严重：
  - 媒体揭露过“9.9元投毒”“千元包上榜”等乱象。
  - 有文章转引称，网信办“清朗”专项行动在打击 AI 语料投毒、虚假信源植入等行为。
- 行业开始规范：有报道称《品牌生成式引擎优化应用规范》已经发布；南昌已有服务商在试“按效果计费”。

**结论：**
- 国内单独做 GEO 是红海，而且合规风险高。
- 差异化方向有两个：**合规、可以量化效果的 GEO**，加上**让商家能被 Agent 直接交易的技术改造**。
- 海外的中小商家这一块，还处在早期。

### A2. 客户与痛点

| 客户 | 痛点 | 优先级 |
|---|---|---|
| 跨境独立站、Shopify 卖家 | 在 ChatGPT 购物推荐里搜不到自己；商品数据不规范，Agent 读不懂 | ★★★★★ |
| 本地服务（口腔、医美、装修、律所、教培、家政） | 用户问豆包、DeepSeek、元宝“附近哪家好”时，答案里没有自己；或者 AI 给出了错误信息 | ★★★★ |
| B2B 制造业、外贸工厂 | 海外采购商用 AI 找供应商，工厂网站却几乎没有结构化信息 | ★★★★ |
| 中小 SaaS、API 公司 | 编程 Agent 读不懂他们的文档，接入不了；AI 推荐同类工具时不提他们 | ★★★ |

### A3. 服务套餐（报价为参考假设）

| 套餐 | 内容 | 国内参考价 | 海外参考价 |
|---|---|---|---|
| **1. AI 可见度诊断** | 用30–100个真实用户问题，测试商家在 ChatGPT、Perplexity、Gemini、豆包、DeepSeek、元宝、Kimi 里的提及率、排名和信息准确性，并和竞品对比，出一份报告 | ¥999–3,000 | $300–800 |
| **2. 基础改造** | 结构化数据（商品、FAQ、本地商家、评价等 Schema 标记）、llms.txt、给 AI 读的事实页（价格、资质、服务范围、营业时间）、各平台商户资料校正、商品数据源规范化 | ¥5,000–20,000 | $1,500–5,000 |
| **3. Agent 可交易化** | 部署 WebMCP 或 MCP 接口（查询库存、预约、询价、下单），或者配置 Shopify 的 Agent 结账；给 SaaS 写 Agent 可读文档和示例 | ¥15,000–50,000 | $3,000–15,000 |
| **4. 月度运营** | 持续监测 AI 可见度，发布合规内容，追踪 AI 带来的流量和线索，出月报 | ¥2,000–8,000/月 | $300–1,500/月 |

**卖法：** 用套餐1做引流，诊断报告本身就是最好的销售工具；靠套餐4拿稳定收入。

### A4. 交付流程（以一个本地口腔诊所为例，约2–3周）

1. **第1–2天，诊断：** 整理本地用户会问的50个问题，比如“XX区种植牙哪家好”“隐形矫正多少钱”，批量在各个 AI 助手里测试，记录诊所有没有被提到、信息对不对、竞品排第几。
2. **第3–5天，梳理事实：** 让客户确认一份准确信息表，包括资质、医生、价格区间、地址、营业时间、医保、案例，作为唯一可信的来源。
3. **第6–10天，技术改造：**
   - 在官网加结构化数据，做一个事实页、FAQ 和 llms.txt。
   - 校正地图、点评、公众号、小程序等商户资料。
   - 给预约功能加 WebMCP 或 API 接口，让 Agent 能直接帮用户预约。
4. **第11–15天，发布内容：** 在知乎、小红书、公众号等 AI 常引用的平台上，发布真实、可核实的科普内容和案例。**不刷量，不伪造评价。**
5. **第三周起，追踪效果：** 每周复测同一组问题，统计来自 AI 的访问和线索，每月出报告，和客户一起看提及率、准确率、线索数的变化。

### A5. 技术栈

- **测试 AI 可见度：** 用 Python 脚本批量调用各模型的 API，或者用浏览器自动化，保存每次回答的截图作为证据。可以先自己写，这部分以后也可以做成产品。
- **网站改造：** Schema 标记（JSON-LD）、llms.txt、Google Merchant Center 商品数据源、Shopify 的 Agent 相关工具、Chrome WebMCP（在网页里注册可被 Agent 调用的功能）。
- **接口：** 用 Cloudflare Workers 或 Vercel 托管 MCP 服务，对接客户的预约、库存或 CRM 接口。
- **追踪：** 在网站分析里识别来自 chatgpt.com、perplexity.ai 等来源的访问，给 Agent 下单单独加标记。

### A6. 获客

- 在行业社群、小红书、抖音发布《XX行业 AI 可见度调查》，比如“我问了豆包100个本地问题，这些诊所被推荐了”。内容本身就能吸引客户。
- 给前10家客户免费做诊断，换取案例授权。
- 找建站公司、代运营公司、Shopify 服务商分成合作：你做 AI 这部分，他们负责客户关系。

### A7. 一人产能与收入测算（假设）

- **产能：** 每月做4–6个诊断，1–2个改造项目，维护15–25个月度客户。
- **收入：** 按国内中位价估算，月费15家 × ¥4,000 = ¥6万/月；加上项目收入 ¥2–4万/月；**合计约 ¥8–10万/月**。
- **瓶颈：** 内容产出和追踪报告。所以要尽快把可见度测试和报告生成做成自动化。

### A8. 风险与对策

| 风险 | 对策 |
|---|---|
| 黑灰产把行业名声搞坏，监管收紧 | 在合同里写明不刷量、不投毒、不伪造信息；所有内容都要可核实；把“合规”作为卖点 |
| 效果难以证明 | 用同一组问题做前后对比，保留截图，只承诺可以量化的指标（提及率、准确率、AI 带来的访问量），不承诺排名第一 |
| 平台免费提供（Meta Muse、Shopify 自带功能） | 做平台不做的部分：跨平台监测、事实纠错、行业内容、对接商家自有系统 |
| 模型更新导致结果波动 | 在报告里说明结果会波动，按月看趋势 |

## B. 个人版 FDE：在企业微信、飞书、钉钉里驻场落地 Agent

### B1. 为什么是现在

- **办公平台都在开放 Agent 能力，而且各有侧重：** 媒体的概括是“钉钉押注流程、飞书深挖知识、企业微信连接客户”。
  - 字节推出了“豆包工作”。
  - 腾讯的 WorkBuddy 已经有第三方 Agent 入驻，比如做出海经营的“小元AI”，能找买家、写开发信、谈生意。
  - 飞书、企业微信、钉钉都推出了 CLI 工具，开源的 OpenClaw 这类 Agent 也可以接入飞书和钉钉。
- **FDE 是热门岗位，但大厂和大公司顾不上中小企业：** 媒体说 FDE 是“AI 最火新岗位”，但也有文章分析 FDE 在中国面临多重障碍，第一批入行的人“至今与高薪无缘”。这说明：
  - 大企业的 FDE 被大厂和系统集成商占了。
  - 中小企业买不起一整个团队，但买得起**一个懂业务的个人**。
- **政府在补贴渠道：** 杭州拱墅上线了面向企业的“AI STORE”，各地 OPC 社区也在对接企业。这些都可以作为获客渠道。
- **平台产品只是半成品：** 平台提供的是积木，中小企业缺的是“把我的业务流程接起来”的人。

### B2. 选择行业：只做1–2个

优先选**流程标准、老板能直接拍板、有明确的钱算得清**的行业：

| 行业 | 高价值场景 | 主要平台 |
|---|---|---|
| **外贸工厂、跨境卖家** | 询盘分级和自动回复、开发信、报价单生成、客户跟进提醒、订单进度查询 | 企业微信、飞书，加邮件和 CRM |
| **连锁门店（餐饮、美业、零售）** | 店长日报汇总、巡店检查、库存和订货提醒、会员回访 | 钉钉、企业微信 |
| **装修、家居** | 线索跟进、报价、工地进度播报、售后工单 | 企业微信（客户在微信里） |
| **律所、财税代账** | 客户咨询初筛、材料收集、到期提醒、合同初审 | 企业微信、飞书 |
| **教培、医疗、口腔** | 咨询转化、预约和回访、课消或复诊提醒 | 企业微信 |

### B3. 标准化的 Agent 场景包（“行业模板 × 平台”）

1. **销售线索 Agent：** 把客户消息自动分级，生成回复草稿，由销售确认后再发送，同时把信息回填到 CRM 或多维表格，超时没跟进就提醒。
2. **知识库客服 Agent：** 把产品手册、价格表、FAQ 接进来，内部员工或外部客户可以直接问。答不了的转人工，并记录没答上的问题。
3. **单据 Agent：** 自动生成报价单、合同初稿、对账单，对接金蝶、用友、管家婆或表格。
4. **管理汇报 Agent：** 自动汇总日报、周报和经营数据，推送异常提醒。
5. **流程执行 Agent：** 请假报销初审、采购审批的预检，结合钉钉宜搭或飞书多维表格的自动化功能来做。

**原则：** 每个场景都要有明确的“省了多少人工时”或“多成交了多少单”的指标。**所有对外发送、涉及钱的操作，都要人工确认。**

### B4. 服务模式与报价（参考假设）

| 阶段 | 内容 | 周期 | 参考价 |
|---|---|---|---|
| **1. 流程诊断** | 驻场1–2天，访谈老板和一线员工，画出流程图，挑出最值得做的3个场景，算清投入产出 | 1周 | ¥3,000–10,000（签项目后可抵扣） |
| **2. 试点项目** | 先做1个场景，上线后试运行2周 | 2–4周 | ¥20,000–60,000 |
| **3. 扩展** | 再做2–4个场景，并培训员工 | 1–3个月 | ¥50,000–150,000 |
| **4. 月度托管** | 运维、调整提示词和知识库、每月出效果报告、新增小需求 | 按月 | ¥3,000–15,000/月 |

**收费技巧：**
- 试点阶段可以约定“按效果收一部分费用”，比如按回复的询盘数，或者节省的工时。
- 一定要把**模型调用费、云资源费**和**服务费**分开算，按实际用量向客户收取。

### B5. 交付流程（以外贸工厂的询盘 Agent 为例，约4周）

1. **第1周：**
   - 驻场诊断，收集过去半年的询盘和报价记录（先脱敏）。
   - 确定分级规则，比如按国家、采购量、行业分为A、B、C三级。
   - 定下验收指标，比如“首次回复时间从8小时缩短到30分钟”“A级询盘100%有人跟进”。
2. **第2周：**
   - 在飞书或企业微信里建机器人。
   - 用 Dify 或扣子编排工作流：邮件或询盘进入 → 模型分级 → 从产品库生成回复草稿 → 发给业务员确认。
   - 用多维表格做轻量 CRM。
3. **第3周：** 接入报价单模板，自动生成 PDF 报价单，加上超时跟进提醒，再做一个老板看的日报。
4. **第4周：** 试运行，每天看出错的案例，调整提示词和知识库，培训业务员，按约定指标验收。
5. **之后：** 转入月度托管，每月复盘一次，挖掘下一个场景。

### B6. 技术栈

- **办公平台接入：** 企业微信（自建应用、智能机器人、客户联系接口）、飞书（机器人、多维表格和 AI 字段、开放平台、CLI）、钉钉（AI 助理、宜搭、开放平台）。
- **编排工具：**
  - Dify：可以私有化部署，适合对数据敏感的客户。
  - 扣子（Coze）：搭建快。
  - n8n：适合做系统之间的连接。
- **模型：** DeepSeek、通义千问、豆包、Kimi 等国内模型的 API。敏感数据尽量用国内模型，或者私有化部署。
- **数据来源：** ERP（金蝶、用友、管家婆）、邮箱、表格、网盘。先从只读接口开始接。
- **可复用资产：** 每做完一个客户，就把工作流、提示词、表格结构沉淀成“行业模板包”。**到第3个客户时，交付时间应该缩短一半以上。**

### B7. 合规要点（务必写进合同）

- **数据归属：** 客户数据归客户所有，你只在项目期间使用；项目结束后删除或移交，并留下书面记录。
- **个人信息：** 用到企业微信会话存档、客户信息时，客户要按《个人信息保护法》履行告知义务。尽量做到“最小够用”，并先脱敏。
- **对外提供服务：** 如果 Agent 是面向公众使用的，而不只是企业内部用，客户需要关注生成式 AI 服务和算法备案的要求，以及《人工智能生成合成内容标识办法》（2025年9月1日起施行）规定的标识义务。
- **责任边界：** 约定 AI 输出需要人工复核；对外发送、报价、付款等操作必须人工确认。你的服务上限是“辅助”，不承担业务决策的后果。
- **账号安全：** 使用客户的企业账号和最小权限的应用凭证，不要把密钥放在个人设备或聊天记录里。

### B8. 获客

- **写行业案例：** 比如《一家30人外贸厂，用飞书 Agent 把询盘回复时间从8小时缩到30分钟》，发在公众号、视频号、行业协会、商会。
- **合作渠道：** 企业微信、飞书、钉钉的服务商或代理商生态，财税代账公司、ERP 实施商（他们手里有大量中小企业客户），OPC 社区，政府的企业服务平台。
- **做免费的“AI 体检”：** 1小时线上诊断，引导客户付费做流程诊断。

### B9. 一人产能与收入测算（假设）

- **产能：** 同时做2–3个试点或扩展项目，托管8–15个月度客户。
- **收入：** 项目收入 ¥5–10万/月，加上托管10家 × ¥6,000 = ¥6万/月；**合计约 ¥10–15万/月**。
- **扩张路径：**
  - 行业模板包成熟后，可以招1–2个实施助理，或者和其他一人公司合作。
  - 或者把高频场景做成平台应用商店里的标准产品，从项目制转向产品订阅。

### B10. 风险与对策

| 风险 | 对策 |
|---|---|
| 项目范围失控，客户不停加需求 | 每个阶段签单独的工作说明书，写清验收指标，新需求走托管额度或另外报价 |
| 平台自己推出同样的功能 | 你的价值在于“懂这个行业的流程并且能落地”，不在于某一个功能；平台功能越强，你交付越快 |
| 客户用完一次就不续费 | 托管服务要定期给出可见的价值：月度效果报告，每季度上线一个新场景 |
| 大模型出错引发纠纷 | 关键操作人工确认；保留日志；合同里写明责任上限 |
| 回款慢 | 预付50%，按阶段收款，托管费按月预付 |

## C. AI 短剧、AI 内容“超级个体”

### C1. 行业现状：机会和泡沫并存

**供给爆炸：**
- 有报道称，每天上线约1,500部 AI 剧。
- 转引中国网络视听协会的数据：2026年一季度 AI 微短剧已经占到上线量的95%左右，但转引的另一组数据称，AI 漫剧的播放量**只有真人短剧的约1/25**。

**市场规模：**
- 转引巨量引擎的数据：2026年漫剧市场有望突破220亿元。
- 海外：据报道，2026年上半年海外短剧 App 收入约12.7亿美元，同比增长13%；另有报道称，出海短剧的投放预算有约八成流向了 AI 短剧，实拍项目减少了约一半。

**淘金热在降温：**
- 有报道标题是《从月入20万到集体停更，AI 漫剧“赛博淘金热”怎么凉了？》。
- 平台撤掉保底之后，承制方“集体断粮”。
- 红果开始治理“高频 AI 脸”，要求角色有差异、版权要合规。
- 微短剧新规落地后，平台审核和采购标准提高。

**政策：**
- 多个省份出台了微短剧扶持政策，比如“备案3天出意见、剧本最高奖励80万”。
- 有报道称，“七城撒下政策红包”，AI 漫剧进入“政策元年”。
- 平台之间的竞争也很激烈：红果在短剧领域一家独大。

**个人案例：**
- 有“3000元做出5亿播放”的案例报道，但同时也有《AI 短剧不是低门槛暴富捷径》这类冷静的报道。
- 出现了“抽卡师”（反复生成、挑选 AI 画面的人）、“一人剧组”等新职业。

**结论：** **拼产能、做同质化爽剧、靠平台保底的模式已经失效。** 个人的机会在**差异化题材、B 端定制和海外市场**。

### C2. 四种可行定位（按推荐程度排序）

| 定位 | 做什么 | 谁付钱 | 为什么适合一人公司 |
|---|---|---|---|
| **1. 品牌和商家定制剧**（最推荐） | 给中小品牌、本地商家做 AI 剧情广告、系列短剧、产品故事 | 商家，按项目付费 | 回款确定，不依赖播放量；可以和 A、B 方向打包卖给同一批商家 |
| **2. 垂类或知识型 AI 剧** | 历史、科普、法律、医疗健康、职场、亲子教育等题材 | 平台分账、知识付费、品牌赞助 | 避开爽剧红海，有人设和专业内容做壁垒 |
| **3. 出海小语种和本地化** | 在已验证的题材基础上，做西班牙语、葡萄牙语、印尼语等小语种版本或本地化改编 | 出海短剧平台的采购和分账 | 海外投放预算在向 AI 剧倾斜，小语种竞争少 |
| **4. 给其他创作者提供工作流和工具** | 角色一致性方案、分镜模板、自动化剪辑流程、提示词库 | 其他创作者或工作室 | “卖铲子”，但要避免变成割韭菜卖课 |

**不推荐：** 纯靠平台分账，批量生产同质化爽剧。

### C3. 制作流程（单人）

1. **选题：** 参考平台热榜和投放数据；需要改编的，从网文平台获取正版授权（网文三巨头都在做短剧）。
2. **剧本：** 用大模型写大纲、分集和台词。**人来定钩子、反转和人设，这是决定成败的环节。**
3. **美术设定：** 设计角色，保证一致性（参考图或专属模型）。**避免“高频 AI 脸”**，确保素材版权干净。
4. **分镜和视频生成：** 用即梦、Seedance、可灵、Vidu、海螺等工具，或者演语的 LibTV、商汤的 Seko 这类 Agent 化工具。“抽卡”（反复生成挑选）的次数要控制在预算里。
5. **配音和音乐：** 用 AI 配音和授权音乐。
6. **剪辑和包装：** 剪映等工具，加字幕、节奏和封面。
7. **合规和发行：** 在显著位置标注“AI 生成”（依据《人工智能生成合成内容标识办法》）；按平台和监管要求完成备案或拿到发行许可；保存素材和授权记录。
8. **复盘：** 看完播率、付费点和评论，指导下一部。

### C4. 商业模式与收入测算（假设）

| 收入来源 | 模式 | 特点 |
|---|---|---|
| **品牌定制** | 单集或系列报价，比如3–10集的剧情广告，¥1–10万/项目（假设） | 最稳定，可以按月签内容合作 |
| **平台分账和扶持** | 按平台规则按播放或付费分成，加上扶持奖金 | 波动大，看爆款 |
| **承制** | 给片方或平台代工 | 平台撤保底后价格被压低，要谨慎 |
| **出海采购、分账** | 卖版权或参与分成 | 要熟悉海外平台和语言 |
| **周边收入** | 工作流模板、咨询、数字分身授权合作 | 做好主业以后再说 |

**一人产能（假设）：** 每月2–4个定制项目，加上1部自己的作品。**建议定制收入占60%以上**，用来支撑自有作品的试错。

### C5. 风险与对策

| 风险 | 对策 |
|---|---|
| 产能过剩，播放量被摊薄 | 不拼数量，拼题材、人设和系列化；B 端定制兜底 |
| 平台政策变化（保底取消、AI 脸治理、审核趋严） | 不依赖单一平台，品牌定制和海外市场分散风险 |
| 版权（角色形象、训练素材、音乐、原著） | 只用授权素材；角色原创；保存授权链条；商用前查清楚工具的授权条款 |
| 内容合规（价值导向、未成年人保护） | 远离低俗、极端“重生”爽文套路；学习新规的红线 |
| 工具成本上涨 | 记录每部作品的生成成本；多个工具组合使用；控制抽卡次数 |

## 四、组合打法：垂直行业的“AI 增长合伙人”

对一人公司来说，更好的做法不是把三个方向当成三门生意，而是**选一个行业，把三件事打包卖给同一批客户**：

```
内容获客（C）→ 被 AI 找到（A）→ 用 Agent 接住并转化（B）→ 数据反馈，指导下一轮内容
```

**示例：口腔诊所 / 装修公司 / 外贸工厂**

1. **C：** 每月做4–8条 AI 剧情短视频或知识短剧，发在抖音、视频号、小红书上获客。
2. **A：** 让诊所或工厂在豆包、DeepSeek、ChatGPT 里被准确推荐，官网能让 Agent 直接预约或询价。
3. **B：** 线索进入企业微信后，Agent 自动分级、回复、提醒跟进，老板每天收到转化日报。

**这样做的好处：**
- **客单价更高：** 一个客户同时付内容费、改造费和托管费。
- **续费率更高：** 三件事互相依赖，客户很难只保留其中一项。
- **能证明效果：** 从曝光、咨询到成交的完整数据都在你手里。
- **行业壁垒会越积越高：** 服务的同行越多，模板、题材库和话术库越丰富。

**组合报价示例（假设）：** 首月搭建费 ¥2–5万，之后每月 ¥8,000–20,000 全包。托管10–15家同行业客户，就是一家稳定盈利的一人公司。

## 五、90天启动计划

| 时间 | 目标 | 关键动作 |
|---|---|---|
| **第1–2周** | 选定行业，打磨工具 | 定1个行业；搭好 AI 可见度测试脚本、1个企业微信或飞书 Agent 模板、1条 AI 短视频的制作流程；入驻当地 OPC 社区，申请补贴和工位 |
| **第3–6周** | 拿到3个标杆客户 | 免费或低价为3家同行做诊断和试点，换取可以公开的案例和数据；每周发布1篇行业调查或案例内容 |
| **第7–10周** | 验证付费意愿 | 用标杆案例转化5–8家付费客户；统一报价和合同模板（包括数据、责任、验收条款） |
| **第11–13周** | 从项目制转向月度托管 | 至少5家转为月度托管；沉淀“行业模板包”；决定下一步是扩到第二个行业，还是招一个助理 |

**要盯住的指标：**
- 诊断转付费的比例
- 单个客户的交付工时（要持续下降）
- 月度托管的续费率
- 月度经常性收入占总收入的比例（目标超过50%）
- 每个客户能证明的效果数字，比如提及率、响应时间、线索数
