# 新创业公司的切入点在哪里

- **依据：** [01_2026年4-9月_创业公司Top100.md](./01_2026年4-9月_创业公司Top100.md) 中的公司和事件
- **说明：** 本文只是分析，不构成投资建议。

**结论：** 最好的切入点是模型公司不想做、做不了、或做了也不划算的地方。这些地方通常需要行业数据、线下交付、合规牌照、接触物理世界，或者深厚的客户关系。

## 一、已经不适合新公司的方向

| 方向 | 为什么难进 | 证据 |
|---|---|---|
| 通用大模型 | 要几百亿美元，还要顶级研究员 | Anthropic 一轮融资650亿；SSI、Thinking Machines 这类“新实验室”靠创始人背景拿钱，普通团队复制不了 |
| 通用AI编程工具 | 已被几家巨头占住，还依赖上游模型 | Cursor 被 SpaceX 收购后，OpenAI 随即停止供应模型；Replit CEO 公开提醒创业公司注意来自模型厂商的风险 |
| 通用个人助理 | 巨头直接竞争 | Instinct 虽然爆火，但要正面对抗 Meta 的 Muse |
| 通用算力和芯片 | 资本门槛是几十亿美元 | Crusoe 一轮39亿，Etched 一轮7亿 |
| 薄套壳的 SaaS 功能 | 模型一升级就被替代 | 有报道称“AI 正在碾压 ChatGPT 之前的一代创业公司”；Miro 被收购时估值跌了90% |

## 二、值得切入的8个方向

### 1. 垂直行业的 AI Agent（最推荐）
- **证据：**
  - 法律：Harvey（155亿）、Legora（谈判中，85亿）
  - 医疗：OpenEvidence（150亿）、Heidi、Commure
  - 住房：EliseAI（40亿）
  - 会计：Rillet，走出隐身模式2年成为独角兽
  - 保险：Corgi，8周融了3轮
  - 本地服务业：Avoca（10亿）、Owner
- **逻辑：** 按“完成了多少工作”收费，而不是按席位卖软件。行业数据、流程和合规就是护城河。
- **还没被占满的细分：** 报税、报关、工程造价、招投标、采购、合规审计、理赔、物业、牙科和兽医诊所、物流调度。

### 2. 给 AI Agent 用的基础设施
- **证据：** Parallel（20亿）、Exa（22亿）；OpenRouter 被 Stripe 以约75亿收购；Temporal（125亿）、Supabase（105亿）、Modal（谈判中，约157亿）。
- **切入口：**
  - Agent 的身份、权限和支付
  - Agent 的可观测性和评测
  - 让 Agent 能读懂的文档和 API
  - 面向 AI 搜索的优化（GEO），参考 Profound（18亿）
- **详细分析：** 见 [03_Agent与基础设施_切入点分析.md](./03_Agent与基础设施_切入点分析.md)。

### 3. AI 训练数据和强化学习（RL）训练环境
- **证据：** Mercor 年化收入超20亿；AfterQuery 5个月估值涨10倍；micro1 年化收入5亿；Snorkel 估值涨近3倍。
- **切入口：** 医学、法律、金融、芯片设计等领域的专家数据；Agent 的强化学习训练环境；机器人数据采集。
- **风险：** 客户高度集中在几家大模型公司。

### 4. 具身智能：做“卖铲子”的，不做整机
- **证据：**
  - 整机的二级市场已经降温：宇树上市后11天市值蒸发约300亿美元。
  - 有收入的公司更受青睐：Skild AI 首次部署10个月后年化收入1亿美元。
  - 零部件也跑出了独角兽：灵巧手公司 AGILINK、端侧芯片公司 SiMa.ai。
- **切入口：** 灵巧手和执行器、机器人数据、仿真和世界模型工具、在具体场景落地（仓储、巡检、餐饮、医院物流）。

### 5. 国防和军民两用技术
- **证据：** Anduril（谈判中，约1000亿）、Stark、Tekever、Castelion、Hadrian、Cathedral。
- **门槛：** 要有政府客户渠道和相关资质。

### 6. AI 带来的能源问题
- **证据：** Emerald AI（10.5亿）、Base Power（谈判中，120亿）、Starcloud、Commonwealth Fusion。
- **切入口：** 电网灵活调度软件、储能、液冷、数据中心能源管理。

### 7. 靠爆款传播的消费级 AI 产品
- **证据：**
  - Lovable 年化收入5亿时只有146名员工
  - Instinct 只有14人，估值100亿
  - Higgsfield 成立18个月年化收入约10亿
  - Wispr Flow 估值20亿
- **风险：** 用户流失快；离模型厂商太近，容易被他们自己做掉。

### 8. 金融基础设施和 AI 安全
- **金融：**
  - 稳定币和跨境美元账户：Augustus、Fasset
  - AI 原生的财务软件：Rillet、Ramp
  - 预测市场（Kalshi、Polymarket）很火，但法院刚裁定 Kalshi 的体育合约属于赌博，监管风险大。
- **安全：** Cyera、Island、Dream、Glow（12亿）、Irregular（谈判中，15亿）。

## 三、中国创业者的特别机会
1. **AI 应用出海：** 参考 Manus、MiniMax 的 Talkie、演语科技。
2. **国产算力的软件生态：** 国产 GPU“四小龙”都已上市，接下来缺的是编译器、推理框架和模型迁移工具。
3. **端侧 AI：** 面壁智能估值超200亿元。
4. **具身智能供应链：** 零部件和整机代工，比做整机品牌更容易活下来。

## 四、判断一个方向能不能做的4个问题
1. **下一代模型发布后，你的产品是变得更好，还是被直接替代？**
2. **你有模型公司拿不到的东西吗？** 比如行业数据、客户关系、牌照、线下交付能力、硬件。
3. **能按结果收费吗？** 比如按完成一次理赔、一次报税收费。
4. **上游依赖有多大？** 如果只依赖一家模型厂商，Cursor 被停止供应模型就是前车之鉴。

**一句话总结：** 大模型公司往上吃掉通用应用，巨头往下收购基础设施，新公司的空间在中间：做深一个行业的工作流，服务好 AI Agent，或者进入物理世界。
