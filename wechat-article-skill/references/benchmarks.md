# 优秀公众号排版实测

**样本**：通过搜狗微信搜索抓取了 12 个头部账号共 29 篇文章，在 375px 手机宽度下读取浏览器计算后的样式。数值取自正文里字数最多的那种段落样式，以及字号或字重明显高于正文的短行（即小标题）。

**局限**：部分样本是招聘或活动推文，文章发布时间跨度也较大。下表只保留编辑类长文的数据，结论看趋势，不要照搬具体数值。

## 正文

| 账号 | 字号 | 行高 | 字距 | 正文色 |
|---|---|---|---|---|
| 晚点 LatePost（对话） | 15–16px | 1.75 | 0.5px | #000 |
| 少数派 | 16px | 1.75 | 0 | #000 |
| APPSO | 15px | 1.67–1.8 | 0–1.5px | #222 |
| 远川研究所 | 15px | 1.87 | 0.5px | #000 |
| 刘润 | 15px | 1.87 | 1px | #4E4E4E–#5F5F5F |
| 极客公园 | 16px | 1.7 | 0.3px | #282828 |
| 三联生活周刊 | 15px | 1.87 | 0 | #000 |
| 丁香医生 | 16px | 1.8 | 0.4px | #545454 |
| 果壳 | 15px | 1.87 | 0.5px | #595959 |

**规律**：
- 字号基本是 15px 或 16px。16px 多见于访谈、科普、面向大众读者的账号。
- 行高集中在 1.75–1.87。
- 字距在 0–1px 之间。
- 正文色分两派：纯黑或近黑（#000、#222）和中灰（#545454–#5F5F5F），几乎没有人用彩色正文。

## 小标题

| 账号 | 样式 | 写法 |
|---|---|---|
| 晚点 LatePost | 20–21px 粗体；左侧品牌图标 + 红色渐变底线 | **观点句**，常常直接引用受访者原话，可以长到两行 |
| 少数派 | 18px 特粗 + 红色「▍」竖条，左对齐 | **短语**，6–10 字，名词性 |
| APPSO | 22px 粗体、橙色 #FF4C00，段前约 40px | 短语或短观点 |
| 远川研究所 | 40px 橙色「01」大序号 + 18px 特粗橙色标题，左对齐 | 短语，6–10 字 |
| 刘润 | 36px 浅灰「—1—」大序号，居中 | 序号本身就是分节标记 |
| 极客公园 | 20px 粗体 + 左侧粗色条 | 短语或问句 |
| 丁香医生 | 20px 粗体、品牌紫，居中 | 口语化短句 |

**规律**：
1. 小标题比正文大 3–7px，并且都加粗。**主流是左对齐**，居中多见于生活类、科普类账号。
2. 装饰只用**一个**元素：竖条、大序号、品牌图标，三选一，没有人叠加使用。
3. 颜色用品牌色，每个账号固定一种。
4. 大序号（远川、刘润）是长文的强节奏标记，适合 4 节以上的文章。
5. 小标题写法分两派：**短语式**（少数派、远川：“选择健康的桌子和椅子”）和**观点句式**（晚点：直接引用受访者的原话）。观点句的好处是读者只扫小标题就能读懂全文主线。

## 其他值得借鉴的做法

| 做法 | 出处 | 本 skill 的对应功能 |
|---|---|---|
| 正文最上方写署名：“文丨某某　编辑丨某某” | 晚点、三联、人物 | front matter 里写 `byline:` |
| 访谈问句前加品牌色块标签（如红底“晚点”），问句整句加粗 | 晚点对话 | `:::qa 提问方` 容器 |
| 金句或结论用品牌色加粗 | 刘润（橙）、APPSO | front matter 里写 `bold: accent` |
| 大号序号分节 | 远川、刘润 | front matter 里写 `h2: big` |
| 访谈、科普类用 16px 正文 | 少数派、丁香医生、晚点对话 | front matter 里写 `size: 16` |
| 标题前加栏目前缀：“栏目名丨”或“栏目名｜” | 晚点独家、晚点对话、APPSO 独家 | 可读性检查时，栏目前缀不计入标题主体字数 |

## 标题

- **常见结构**：
  - 栏目前缀 + 竖线 + 主体，例如“晚点对话丨人物：观点”
  - 人名 + 冒号 + 一句金句
  - 用「」或书名号标出核心概念
- **长度**：编辑类长文的标题多在 14–27 字；带栏目前缀的独家、快讯类可以到 35–45 字，但订阅号列表里只会显示前两行。
- **有信息量**：好标题要么给出结论（“战略的本质是不赌”这类判断句），要么给出具体数字，很少只制造悬念。

## 正文结构实测（2026 年 9 月）

**样本**：晚点 LatePost 3 篇长文（4000–7700 字，官网版本）、少数派 2 篇评测（3500–9700 字）。统计的是正文段落（≥15 字）和页面元素。

| 指标 | 晚点（3 篇） | 少数派（2 篇） |
|---|---|---|
| 段落字数中位数 | 76–121 | 78–123 |
| 段落字数 75 分位 / 90 分位 | 94–159 / 118–177 | 99–161 / 122–192 |
| 超过 110 字的段落 | 13–19 段 | 8–51 段 |
| 二级小标题 | 每篇 2–3 个，**不编号**，全是判断句（“一年付出 560 亿元，赛力斯想自己主导”） | 短语或“主标题：副标题” |
| 章节标签（PART / 01 / 05 / 导读） | 0 | 0 |
| 导读框、“写在最后”卡片 | 0 | 0 |
| 加粗 / 引用块 / 列表 | 0 / 0 / 2–8 | 0 / 0–1 / 1–2 |
| 图片 | 5–13 | 26–66 |
| 结尾 | 停在一个对比场景或判断上，然后“题图来源：……”；没有互动问题 | 购买建议、声明，或一句“欢迎在评论区交流” |

**规律**：
1. 装饰性文字几乎为零。小标题靠内容本身让人停下，不靠“PART 03”“01 / 05”这类标签。
2. 段落比“≤110 字”宽松：多数在 60–120 字，150 字以上才少见。
3. 视觉锚点主要是**图片和图表**，不是提示卡、列表或金句框。正文里 15–20 段连续文字很常见，中间靠配图断开。
4. 开头直接进入场景或判断，不设导读框；结尾不总结、不升华，也常常不提问。
