# 排版系统

设计语言叫**“留白”**：东方式的克制，加上杂志式的层级。层级靠**留白和字重**区分，而不是靠框线和色块。全文只用一个强调色。

## 字体与间距

| 元素 | 字号 | 行高 | 字距 | 上下间距 |
|---|---|---|---|---|
| 正文 `p` | 15px（`size: 16` 时为 16px） | 1.85（16px 时为 1.8） | 0.5px | 下 20px |
| 章节 `##` | 18–19px 粗体 | 1.5–1.6 | 1–2px | 上 52–56px / 下 24–28px |
| 小节 `###` | 16px 粗体 | 1.6 | 1px | 上 36px / 下 14px |
| 小标 `####` | 15px 粗体（强调色） | 1.6 | 1px | 上 28px / 下 10px |
| 导读 / 引用 / 卡片内文 | 14px | 1.85 | 0.5px | — |
| 金句 | 17px 粗体居中 | 1.8 | 1px | 上下 44px |
| 图注 / 脚注 | 12px | 1.6–1.7 | 1px | — |
| 代码 | 12.5px 等宽 | 1.75 | 0 | 上下 24px |

颜色的分工：正文深灰（不用纯黑）；标题比正文更深；辅助文字用浅灰；主题色只用在序号、标记、重点、链接和组件标签上。

这些数值参考了头部账号的实测数据（见 `benchmarks.md`）：主流行高在 1.75–1.87，小标题比正文大 3–7px 并且加粗、左对齐，装饰元素只用一个。

## 主推主题：借鉴 Claude / OpenAI，但做了自己的改动

章节**默认不编号**；front matter 写 `numbered: true` 才显示序号，而且只写**「01」**（等宽小字）。早期版本写成「01 / 05」，另两套主题写成「PART 01」；实测头部账号都不用这类标签（见 `benchmarks.md`），已去掉。

### `clay` 陶土（默认）：借鉴 Claude 的暖调编辑风格

| | Claude 的做法 | 陶土的做法 |
|---|---|---|
| 底色 | 大面积奶油色画布 | 默认白底，只在导读、卡片、代码块上用燕麦色 #F4F0E8；需要整页纸感时用 `paper: true` |
| 强调色 | 珊瑚橙 | 更深、更偏红的陶土色 #C2603E，接近中文语境里的“赭石” |
| 标题 | 西文衬线字体 | **中文宋体**标题（系统字体，无需加载），正文仍用无衬线，提高手机可读性 |
| 金句 | — | 宋体 18px，左对齐，上方一道 22px 的陶土色短线 |
| 组件 | — | 12px 大圆角色块，没有边框和左竖线 |
| 结尾 | — | 中文收尾「— 完 —」 |

### `mono` 素白：借鉴 OpenAI 的极简黑白风格

| | OpenAI 的做法 | 素白的做法 |
|---|---|---|
| 颜色 | 几乎只有黑白灰 | 黑白灰 + **一个信号橙 #F2542D**，只用在序号方块、金句左线、链接下划线、脚注编号上 |
| 章节 | 大号无衬线标题 | 章节上方加一条细线，序号前有一个 6px 的橙色方块 |
| 导读 | 大号引言 | 16px 引言，没有色块，下方一条细线 |
| 列表 | — | 黑色小方块；有序列表用等宽灰色「01 02 03」 |
| 表格 | — | 表头用黑色细线，不用色底 |
| 分隔 | — | 一条纯细线 |

主题可以在 front matter 里用 `theme:` 指定，也可以用命令行 `--theme` 覆盖。预览页顶部能实时切换全部六套主题。front matter 加 `paper: true` 会给全文铺一层纸色底，带 12px 圆角。

## 扩展组件

```markdown
:::lead [标签，可省略；省略时不显示标签]
2–3 句导读，放在文章开头。
:::

:::quote [出处]
金句。全文 1–2 处即可。
:::

:::tip [标签]      提示（主题色）
:::note [标签]     要点
:::info [标签]     说明
:::warn [标签]     注意（固定用红色）

:::card [标题]
总结、清单、写在最后。
:::

:::qa [提问方，默认“问”]
提问方：问题会渲染成色块标签 + 粗体。
受访者：回答里名字加粗，其余是正文。
:::

:::center
居中文字，每行单独换行。
:::

:::footer
结尾的关注引导、账号介绍。
:::
```

组件内部可以写任意 Markdown，包括列表、粗体、嵌套组件。

## 自动处理

- **盘古之白**：中文与英文、数字之间自动加空格（front matter 设 `pangu: false` 可关闭）。
- **弯引号**：中文语境下的 `"…"` 自动转成 `“…”`，英文原样保留。
- **外链转脚注**：正文里显示 `[1]`，文末“参考资料”区列出完整链接，同一链接自动去重。
- **结尾标记**：默认不加；front matter 设 `end: true` 时，文末显示主题自带的标记（如 `— END —`）。

## 公众号兼容性约束（脚本已处理，手写时要注意）

- 只能用内联 `style`：`<style>`、class、id、`<script>` 都会被删掉。
- 不要用 `position`、`float`、web 字体、`<iframe>`、表单元素。
- 正文外链会被去掉，只有公众号文章链接能点击。
- 图片：编辑器只会转存 http/https 图片，本地路径复制不过去。front matter 写 `image_base: <图片目录的公网地址>`（或命令行 `--image-base`），相对路径会自动拼成公网地址；`--check` 会提示没有公网地址的本地图片。GitHub 仓库推荐 jsDelivr（`cdn.jsdelivr.net/gh/用户/仓库@提交号/目录`），`raw.githubusercontent.com` 在国内可能访问不了，转存会失败。转存失败时，只能在编辑器里手动上传。
- 深色模式下，公众号会自动反转颜色。背景只用低饱和的浅色（例如 `#F8F1EE`），不要用大面积纯白或纯黑色块。
- 空标签可能被删掉：装饰性元素用带尺寸的 `inline-block` span 实现，并包在有内容的 `p` 里。
- **行高写成 em，且不小于字号**（如 `line-height:1.85em`）。不带单位的 `1.85` 和 `line-height:0` 都会被公众号粘贴检查报“行高异常：行高小于字体大小，可能导致文字重叠”。脚注上标用 `line-height:1em`；分割线和装饰短线用带样式的 `<hr>`，不再用“字号 0 + 行高 0”的 `p`。`--check` 会自检生成的 HTML，发现这类写法会报 `HTML` 警告。
