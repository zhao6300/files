# 内容功夫：写出头部账号水准的文章

排版决定读者能不能读下去，内容决定读者会不会转发、收藏、记住你。
这份指南讲后者。参照对象是晚点 LatePost、财新、三联生活周刊、人物、远川研究所、《经济学人》这类账号和刊物，它们的共同点是：**有信息增量，有明确判断，每句话都站得住**。

写作分四关，依次过：**选题 → 立论 → 取材 → 改稿**。最后用第 7 节的评分表自查。

## 1. 选题：先回答“为什么是现在，为什么是你”

写之前用三句话测试选题，任何一句答不上来，就换角度：

1. **新在哪里**：这件事最近发生了什么变化？（新事实、新数据、新政策、新产品，或者老问题出现了新的解法）
2. **和谁有关**：哪一类读者会因此改变判断或行动？越具体越好。“所有人”等于没有人。
3. **我能多给什么**：读者刷完热搜、看完通稿之后，这篇文章还能多给他什么？

大题目要**切小**。“AI 会不会取代程序员”是话题，不是选题；“AI 写代码之后，初级程序员的面试题变了什么”才是选题。切小的方法：限定人群、限定时间、限定一个具体场景、限定一个数字。

## 2. 立论：写下一句话的核心判断

动笔前，在草稿最上方写一张**论点卡**（交付骨架时一并给用户看）：

```
核心判断：一句话，≤40 字，必须是可以被反驳的陈述句
为什么反直觉：大多数人现在怎么想
最强证据：1 条事实或数据（附来源）
最强反方：反对者最有力的理由，以及我怎么回应
读者收获：读完之后，读者会改变什么判断或行动
```

检验核心判断的三个问题：
- **能不能被反驳？**“教育很重要”没法反驳，所以没有信息量；“县城家长花在课外班上的钱，回报率低于存银行”可以反驳，所以值得写。
- **所以呢？**连问两次“所以呢”，一直问到读者会因此改变行动的那一层。
- **一句话能说清吗？**说不清，说明自己还没想清楚。先别写，回去想。

### 独特观点从哪里来

独特不等于唱反调。头部账号的“新观点”几乎都来自下面几种方法，每篇至少用一种：

| 方法 | 做法 | 例子 |
|---|---|---|
| 拆数字 | 把一个总数拆成结构、分母、增速，找到被平均掉的部分 | 整体销量涨 20%，其中 80% 来自一个价位段 |
| 换参照系 | 换一个时间、地区或行业来比较 | 拿 2008 年的日本、1990 年代的美国来对照 |
| 看二阶效应 | 不问“会怎样”，问“然后呢”，看到第二、第三层后果 | 外卖变便宜，然后呢？写字楼食堂和便利店先受影响 |
| 找利益相关方 | 列出所有受影响的人，问谁在沉默、谁在得利 | 一项补贴政策，真正拿到钱的是厂商还是消费者 |
| 追问机制 | 不停在“是什么”，讲清楚“为什么会这样” | 不只说“价格战”，讲清楚为什么这个行业只能打价格战 |
| 找反例 | 找一个不符合主流解释的案例，从这里切入 | 大家都在裁员，为什么有一家反而在扩招 |
| 一线细节 | 用亲历、访谈、原始文件里的细节替代二手转述 | 财报附注里的一行字，比新闻稿里的十句话有用 |

**反共识的前提是证据**。只有立场、没有证据的“反常识”，是标题党的另一种写法。

## 3. 取材：让每句话都站得住

### 证据等级（从强到弱）

1. 原始数据和文件：财报、统计公报、判决书、论文、官方公告
2. 当事人原话，写明身份和场合
3. 权威媒体的独立报道
4. 可以复现的亲自观察或实验
5. 行业研究报告（要注意谁出钱做的）
6. 二手转述、自媒体文章：只能当线索，不能当证据

**核心判断至少要有一条来自第 1–3 级的证据**。

### 信源写法

- 写清楚是谁说的、在哪说的、什么时候：“国家统计局 9 月 15 日发布的数据显示”，不要写“有数据显示”。
- 不要写“有研究表明”“专家认为”“据统计”“业内人士称”，除非紧接着写出具体名字。匿名信源要说明身份和匿名原因：“一位不愿具名的某车企销售总监”。
- 数字要带单位、时间范围、口径：“2025 年全年，A 股上市公司的研发投入同比增长 8.3%”。
- 引语要忠实原意。压缩可以，改变意思不行。

### 事实核查清单（交稿前逐条过）

- [ ] 每个数字都能指出出处，而且口径一致（同比还是环比，名义值还是实际值）
- [ ] 人名、机构名、职务、日期、引语原文都对照信源查过，不凭记忆；日期写绝对日期，不写“上周五”
- [ ] 分清已发生、已宣布、计划中：“将提出”不能写成“提出”，“计划”不能写成“已完成”
- [ ] 数据的限定条件没有丢：样本是怎么挑的、原作者自己声明了什么局限
- [ ] 没有把相关写成因果（“A 之后 B 发生了”不等于“A 导致了 B”）
- [ ] 没有用个案推出全体
- [ ] 需要实时信息的内容用联网工具查过；查不到的，明确写“截至某日”或者删掉
- [ ] **不编造**任何数据、引语、案例、来源。缺材料时，在稿子里用【待补：……】标出来，告诉用户去找

## 4. 结构：让读者一直有理由往下读

每一节都要回答读者心里的下一个问题。写完大纲，把所有小标题连起来读一遍：**只看小标题，能不能读懂全文的论证？**

| 文体 | 骨架 | 参照 |
|---|---|---|
| 新闻 / 快讯 | 倒金字塔：最重要的事实放第一段（谁、做了什么、为什么重要），然后是背景、各方反应、影响 | 财新、晚点快讯 |
| 深度报道 | 场景开头 → 核心判断 → 分几条线索展开 → 回到开头的场景 | 人物、三联 |
| 分析 / 评论 | 现象 → 流行解释 → 为什么不够 → 我的解释 + 证据 → 边界 → 对读者意味着什么 | 远川、经济学人 |
| 访谈 | 把最有冲击力的观点提到标题和第一节 | 晚点对话 |

几条通用的结构规则：
- **结论前置**。第一屏就要让读者知道这篇文章的判断，悬念只用在叙事上，不用在观点上。
- **每一节只推进一步**。一节里出现两个论点，就拆成两节。
- **给反方留一节**。主动写出最强的反对意见并回应，比回避它更有说服力。
- **结尾不重复全文**。要么往前推一步（接下来该看什么信号），要么回扣开头的场景。

## 5. 精炼：删掉一切不干活的字

好文章的秘诀不在多写，在于删。改稿时按这个顺序删：

1. **删段**：删掉以后论证不受影响的段落。背景介绍通常能砍掉一半。
2. **删句**：删掉重复论点的句子、复述上一段的过渡句、“下面我们来看看”这类预告句。
3. **删词**：删掉下面这些词，意思几乎都不会变。

| 类型 | 典型写法 | 改法 |
|---|---|---|
| 空洞开头 | 随着……的发展、在当今时代、众所周知 | 直接写事实 |
| 套话总结 | 总而言之、综上所述、总的来说 | 删掉，直接写结论 |
| 虚假强调 | 值得注意的是、需要指出的是、不可否认 | 删掉；真正重要的话不需要预告 |
| 模糊对冲 | 在某种程度上、可以说、或许、一定程度上 | 要么给出条件，要么删掉 |
| 空洞形容 | 非常重要、极其关键、意义深远、巨大的 | 换成数字或例子 |
| 行话黑话 | 赋能、抓手、闭环、打通、底层逻辑、颗粒度 | 换成具体的动作 |
| AI 腔 | 让我们一起、不仅……更是……、这不仅是……更是……、在这个……的时代、一场……的革命 | 删掉，改成直接陈述 |
| 排比凑数 | 首先……其次……再次……最后…… | 改成列表，或者只留真正并列的两三项 |

4. **换词**：抽象词换具体词（“提升效率”换成“从 3 天缩短到 4 小时”），被动句换主动句，名词化的动词还原（“进行了讨论”换成“讨论了”）。

**目标**：终稿比初稿短 20%–30%。

## 6. 语言：准确比漂亮重要

- **一句话只说一件事**，主语明确。读者读到句尾时，还记得主语是谁。
- **动词比形容词有力**：“它撕开了价格底线”比“它带来了巨大冲击”好。
- **判断要有分寸**：确定的事写确定，推测的事写明是推测，并写出依据。不要把一切都写成“或许”，也不要把推测写成定论。
- **比喻最多一个一节**，要帮助理解，不要只是为了修辞。
- **金句要从论证里长出来**，不要生造。一句好的金句，是全文判断最凝练的版本。全文一两句就够，每段都有金句等于没有。

语言上的“人味”（细节、节奏、克制、AI 味清单）另见 `human-voice.md`。

## 7. 交稿前自评

按下面 7 项逐项打分（1–5 分）。**任何一项低于 3 分，或总分低于 28 分，先改稿再交付**；短板只能靠用户材料补时，照实报分、写清缺什么，不编造凑分。交付时把分数和最弱的一项告诉用户。

| 维度 | 5 分的标准 |
|---|---|
| 信息增量 | 至少有一个读者在别处看不到的事实、数据或视角 |
| 观点清晰 | 一句话能复述核心判断，而且这个判断可以被反驳 |
| 论证扎实 | 每个关键论点都有具名来源的证据；主动回应了最强的反方 |
| 结构 | 只读小标题就能看懂主线；第一屏就给出判断 |
| 精炼 | 没有第 5 节列出的套话；删掉任何一段都会有损失 |
| 准确 | 通过第 3 节的事实核查清单，没有编造的内容 |
| 人味 | 至少一个有信息量的真实细节；读者能感觉到作者在场、有自己的口气；大声读不像念稿子（见 `human-voice.md`） |

`md2wechat.py --check` 会自动标出套话、AI 腔、模糊信源、句子节奏过于均匀等问题，但它只能查表面。观点有没有信息量、文字有没有人味，要靠上面这张表。
